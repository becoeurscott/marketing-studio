# Marketing Studio (web)

Frontend-only Next.js 16 prototype of an AI marketing creative studio. Mock data, mock async APIs, localStorage persistence.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # must pass with zero TS/ESLint errors
```

Read `../SPEC.md` for the product spec and `src/components/README.md` for the architecture, store, mock API and conventions.
