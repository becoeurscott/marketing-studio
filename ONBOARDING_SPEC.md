# Sokozia — onboarding spec (campaign-first)

Core promise: **Une photo produit → une campagne marketing complète.**
The onboarding must feel like creating the first campaign, not a SaaS setup wizard. The user's product photo is the protagonist on every screen. All UI text in French.

Flow:
1. **Opening** — "Transformez une photo produit en campagne complète." Sub: photos produit, vidéos UGC, pubs, textes, générés pour votre marque en quelques minutes. CTA "Créer ma première campagne →"; secondary "J'ai déjà un compte". Very visual: one product transforming into Photo produit → Vidéo UGC → Pub → Post social → Campagne.
2. **Product upload** — "Que voulez-vous promouvoir ?" Upload zone, "Choisir depuis l'appareil", or "Utiliser un produit exemple" (important: lets users try without a photo).
3. **Product analysis** — animated checklist: Analyse du produit…, ✓ Produit détecté, ✓ Catégorie identifiée, ✓ Caractéristiques visuelles analysées, ✓ Composition comprise, ✓ Opportunités créatives trouvées. Then "Je l'ai trouvé." + product name (e.g. Luma Glow Serum), category (Soin · Beauté), one-line description, product image. "C'est correct ?" [C'est bon →] / Modifier les détails.
4. **Goal** — "Quel est votre objectif ?" visual cards: 🚀 Lancer un produit / 💰 Vendre plus / 📱 Développer mes réseaux / 🧪 Tester de nouvelles créas / ✨ Je ne sais pas (Sokozia décide).
5. **Platforms** (multi-select) — "Où vivra cette campagne ?" TikTok, Instagram, Facebook, YouTube, Pinterest, Google. Adaptive feedback, e.g. TikTok+Instagram → "Parfait. J'optimise la campagne pour le format vertical court."
6. **Creative direction** — "Quelle sensation pour votre marque ?" 4 large visual cards: LUXE (Premium, Élégant, Éditorial), ÉPURÉ (Minimal, Moderne, Lumineux), UGC (Authentique, Humain, Social-first), AUDACIEUX (Énergique, Coloré, Accrocheur) + "Surprenez-moi ✦".
7. **Brand (optional)** — "Personnalisez-la." Upload brand kit or "Je le ferai plus tard". If uploaded: ✓ Logo détecté, ✓ Couleurs détectées, ✓ Ton identifié.
8. **Boldness** — "Jusqu'où on ose ?" PRUDENT (Éprouvé & soigné) / CRÉATIF (Distinctif & engageant) / FOU (Inattendu & percutant). CTA "Construire ma campagne →".
9. **Generation moment** — full screen "Construction de votre campagne…" step list checking off one by one (Analyse du produit, Direction créative, Photos produit, Accroches, Concept UGC, Textes pub, Variantes par plateforme, Préparation de la campagne). No generic spinner.
10. **Reveal 1: photos** — "Votre produit vient d'avoir son shooting. 📸" 4 images grid. "Sans photographe." Actions: Modifier / Générer plus / Ajouter à la campagne.
11. **Reveal 2: UGC** — "Maintenant, rendons-le humain." Vertical mock video, virtual creator "Maya · Lifestyle", quote "Ok, je teste ce sérum depuis une semaine…", "Concept UGC 15 s · TikTok / Reels". CTA "Générer un autre créateur".
12. **Reveal 3: ads** — "Votre produit mérite plus d'une pub." Créa A/B/C each with visual, headline, primary text, CTA, platforms.
13. **Reveal 4: copy** — "Votre campagne a une voix." Accroche, Légende, Script UGC, Description produit; actions Copier / Régénérer / Modifier.
14. **Full campaign** — "Votre campagne est prête. ✦" summary card: Photos produit 4, Vidéos UGC 2, Variantes pub 6, Posts sociaux 8, Accroches 12, Légendes 6, Textes produit 3 → TOTAL 41 contenus. "Une photo produit. Une campagne."
15. **Platform formatting** — campaign branching to TikTok 9:16 / Instagram 9:16 / YouTube 16:9. "Chaque créa est préparée pour la plateforme ciblée."
16. **Value reveal** — "Regardez ce que vous venez de créer." 1 photo → … = 41 contenus. "Sans photographe. Sans designer. Sans rédacteur. Sans agence."
17. **Workflow avoided** — Traditionnellement: photographe → designer → vidéaste → rédacteur → designer pub → community manager → agence. Sokozia: UN PRODUIT → SOKOZIA → CAMPAGNE COMPLÈTE. "Créez votre marketing sans monter une équipe marketing."
18. **Campaigns** — campaign card (Overview/Assets/Ads/Videos/Copy/Calendar tabs, 41 assets, 6 variantes, 3 plateformes). "Ouvrir la campagne →".
19. **Calendar** — "Et Sokozia peut aussi la planifier." LUN Reel Instagram, MAR UGC TikTok, MER Carrousel produit, JEU Story Instagram, VEN Pub TikTok. "Votre campagne n'est pas seulement créée. Elle est organisée."
20. **Account** — only now. "Sauvegardez votre campagne. Vos 41 contenus sont prêts." Continuer avec Google / Apple / Email (Apple prominent on iOS).
21. **Paywall** — campaign preview on top. Gratuit 0 $ / Creator 12 $/mois / Studio 29 $/mois / Agency 59 $+/mois (feature lists per spec). Never "S'abonner": CTA "Lancer ma campagne →" / "Continuer à créer →".
22. **After** — land in the campaign workspace, not a dashboard: "Campagne prête · 41 contenus", AUJOURD'HUI ✓ list, ENSUITE → suggested next actions.
